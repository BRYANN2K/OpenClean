# OpenClean

Open-source, transparent macOS cleaner. A community alternative to CleanMyMac.

Status: design phase. See [the core design spec](docs/superpowers/specs/2026-10-12-openclean-core-cleanup-design.md).

Clean-room: the feature set was informed by inspecting CleanMyMac metadata and UI strings only. No MacPaw code, binaries or assets are used.
