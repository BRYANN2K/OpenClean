# Code of Conduct

OpenClean follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive in issues, pull requests and reviews, assume good faith, and
keep discussion about the work. Harassment, insults, and personal or political attacks are not accepted.

This applies in all project spaces (issues, pull requests, discussions) and when you represent the
project elsewhere.

## Reporting

If someone's behaviour is a problem, contact the maintainer,
[@leoAnimesh](https://github.com/leoAnimesh), privately. Reports are kept confidential. The maintainer may
edit or remove comments, lock threads, or block contributors who don't follow this code, as described in
the Contributor Covenant's enforcement guidelines.

Security issues are not conduct reports: see [SECURITY.md](SECURITY.md).
