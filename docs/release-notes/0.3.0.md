What's new since 0.2.1.

## Safety fix: Poetry environments and Deno data

In 0.2.x the generic **App caches** rule treated everything in `~/Library/Caches` as a regenerable cache.
Two tools keep data there that isn't a cache: Poetry keeps its virtual environments in
`~/Library/Caches/pypoetry/virtualenvs`, and Deno keeps localStorage in `~/Library/Caches/deno/location_data`.
App caches deleted them immediately, without quarantine. 0.3.0 excludes them, along with every other
`~/Library/Caches` folder that now has its own rule. Poetry environments are now a separate Review rule
that goes to quarantine, and Deno's localStorage is never touched. If a Poetry project stopped working
after a clean, run `poetry install` in it to rebuild the environment.

## Highlights

- **Developer and AI caches:** new rules for npx, Bun, Deno, Yarn 2+, Corepack, node-gyp, Electron,
  Playwright, Puppeteer, Cypress, uv, Poetry, conda, pre-commit, Go, Cargo, Maven, Coursier, Ivy,
  Gradle, SwiftPM, pub, Bundler, Composer, Terraform, JetBrains, VS Code, Cursor and Unity, and for
  Hugging Face datasets, PyTorch Hub, Whisper, Keras, TensorFlow Datasets and Kaggle.
- **Old projects:** `node_modules`, Python virtual environments, Cargo `target` and build output
  (SwiftPM, Gradle, Maven, Flutter, Next.js and similar) in projects you haven't changed for 30 days.
  These are Review items: nothing is selected for you, and they go to quarantine, so you can restore them.
- **Project folders:** projects in Documents or Desktop are skipped unless you add their folder under
  Settings → Project folders. Only build folders that OpenClean recognises can be cleaned there. Your
  own files in those folders are still never removed.
- **Go module cache:** `~/go/pkg/mod` is now cleaned properly. Go makes it read-only, so before deleting
  it OpenClean gives you write permission on its folders, the same result as `go clean -modcache`.
- **Scan reminder (optional, off by default):** a weekly or monthly read-only scan that tells you how
  much can be cleaned. It never cleans anything itself.
- **Clearer skipped items:** after a clean, Smart Scan lists anything it left in place and says why
  (open in another app, changed since the scan, protected) and whether scanning again would help.
- **CLI:** `openclean apps list` and `apps uninstall` (to quarantine, with `--dry-run` and `--json`),
  `openclean space large` and `space duplicates` (read-only), and `openclean performance`.
- **Languages:** the app is now available in German, Spanish, French, Japanese and Simplified Chinese,
  following your macOS language. The translations are machine-assisted; corrections from native speakers
  are welcome (see CONTRIBUTING.md). The CLI stays in English.
- **Screenshots:** the README now shows every screen and a short Smart Scan demo.
- **Cleanup list:** the selected category and rule are highlighted like the sidebar instead of in the
  system accent colour.
- **Homebrew:** this repository is now a Homebrew tap for both the app and the CLI (see Install below).
