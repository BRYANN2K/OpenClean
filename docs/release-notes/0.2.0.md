OpenClean's first release: an open-source, transparent cleaner for macOS. Every cleaning rule is
readable YAML, anything that isn't trivially regenerable goes to a quarantine you can restore from, and
there are no accounts or analytics.

## Highlights

- **Smart Scan:** system junk, user caches and logs, browser caches, Trash, Mail attachments, old iOS
  backups, developer caches (Xcode, npm, Yarn, pnpm, pip, Cargo, Gradle, CocoaPods, Homebrew) and AI
  model caches (Ollama, LM Studio, Hugging Face).
- **Uninstaller:** removes an app together with its `~/Library` leftovers as one quarantine session, so
  an uninstall can be undone.
- **Space Lens:** an interactive disk map, a large & old files finder and a duplicate finder. Removals go
  to the Trash and nothing is pre-selected.
- **Performance and menu bar:** live CPU and memory in the menu bar, heavy apps with Quit/Force Quit,
  launch agents and maintenance tasks.
- **Safe by design:** Safe / Review / Caution levels, a hard deny-list, checks just before each removal,
  and History and Restore for 1–90 days.
- **Software Update:** a daily check against GitHub (can be turned off); updates are verified against
  the release checksums and the developer signature, installed in place, and the previous version stays
  in History.
- **CLI:** `openclean scan` / `clean` with JSON output, for scripts and CI.

The app is signed with a Developer ID and notarized by Apple.
